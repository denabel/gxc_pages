Indicator catalogue

This page lists all indicators available in gxc (version 1.0.0) and the catalogues that provide them. The tables are generated from the package itself. In R, lookup("<indicator>") shows the same information for a single indicator, and gxc_indicators() lists all of them.

Which catalogue should I use?

  • Germany, high resolution: the DWD catalogues (1 km). No API key needed.
  • Daily data elsewhere, or long baselines: "arco-era5-land-daily". It reads hourly ERA5-Land data directly from ECMWF’s cloud-optimised store, aggregates them to daily values and is usually much faster than the CDS catalogues, whose requests can wait in a queue for up to an hour. Its values match "derived-era5-land-daily-statistics". It is still experimental.
  • Over sea, or indicators not in ERA5-Land: the ERA5 single-levels catalogues (0.25°).
  • Monthly data: the ERA5 or DWD monthly catalogues.

Units and daily statistics

For daily ERA5 and ARCO catalogues, the statistic argument of link_daily() sets how the hourly values of a day are combined: "daily_mean" (default), "daily_maximum", "daily_minimum" and, for accumulated indicators, "daily_sum".

Accumulated indicators such as precipitation, snowfall and radiation are stored as hourly amounts. Their daily mean is therefore an amount per hour (e.g. m/h). Use statistic = "daily_sum" for daily totals (m/day). Monthly ERA5 values of these indicators are mean daily totals (m/day). The .unit column in the output of link_daily() and link_monthly() always states the unit of the returned values.

Temperatures from ERA5 are in Kelvin (K), from DWD in degrees Celsius.

Notes per indicator

  • Monthly mean of daily totals. Applies to: total_precipitation, snowfall, downward_uv_radiation_at_the_surface
  • Hourly amounts; use statistic = "daily_sum" for daily totals. Applies to: total_precipitation, snowfall, downward_uv_radiation_at_the_surface, surface_solar_radiation_downwards, surface_thermal_radiation_downwards
  • Daily totals. Applies to: precipitation
  • Monthly totals. Applies to: precipitation

Planned datasets

  • Hourly resolution, e.g. ERA5-Land hourly data from 1950 to present (currently only used internally to compute daily values) and ERA5 hourly data on single levels from 1940 to present
  • Thermal comfort indices derived from ERA5 reanalysis
  • Fire burned area from 2001 to present derived from satellite observations
  • Emission Database for Global Atmospheric Research (EDGAR)
  • CAMS global greenhouse gas reanalysis (EGG4)
